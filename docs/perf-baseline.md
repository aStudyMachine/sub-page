## 2026-11-24 稳定性修复前后对照

Windows 11、Node v24.22.1。优化前使用 `1fdef33`，前后使用相同的测试脚本与样例库。扫描复测使用 `npm run perf`。将同一份 `tests/perf/scan.test.ts` 放入基线检出，可重跑旧扫描器。

| 假库 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 混合树 100 / 1 000 / 5 000 / 10 000 页，单次 | 0.9 / 4.8 / 21.8 / 75.7 ms | 0.9 / 4.1 / 21.5 / 70.5 ms |
| 宽树 10 000 节点，7 次中位数 | 13.6 ms，列目录 2 次 | 12.8 ms，列目录 1 次 |
| 深树 3 360 节点、目录深度 32，7 次中位数 | 25.3 ms，列目录 386 次 | 25.3 ms，列目录 385 次 |

宽树和深树前后的根顺序、节点归属、子项顺序及后代计数分别得到相同摘要 `a73dd9217ea7` 和 `de2429957c3d`。扫描复用根目录列表，并在生成索引时自底向上累计后代页数。此样本上的耗时变化较小。

Obsidian 复测使用 `node tests/perf/obsidian.mjs <基线产物目录> <当前产物目录>`。脚本为每组产物复制样例库和独立 profile，添加 4 000 篇笔记。两组均索引 4 054 个节点，侧栏显示 51 行。

| Obsidian 场景 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 冷启动到页面树可用，单次，包含宿主启动与信任流程 | 1 471 ms | 1 462 ms |
| 宿主已启动时重新启用插件到首屏行出现，3 次中位数 | 22.6 ms | 19.7 ms |
| 上述插件首扫，3 次中位数 | 5 ms | 5 ms |
| 单笔记保存到同步视图重绘完成，3 次中位数 | 3.3 ms | 3.3 ms |

每次单笔记保存均触发 0 次全树扫描、0 次根目录列举、1 次侧栏重绘和 3 次正文块刷新回调。当前样本的插件首屏低于 300 ms 优化阈值。结果适用于本次 51 行的可见首屏，全部展开和更大真实库需要单独测量。
