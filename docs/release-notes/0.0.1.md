## 0.0.1

首个可用版本。把已有的笔记库直接变成一棵页面树，不需要改造目录结构。

### 页面树

- 页面根内的任意笔记都是页面；带同名目录的笔记自动成为父页面，目录里的笔记是它的子页面。
- 没有同名笔记的目录作为分组目录出现，不会消失，也不会被改写。
- 侧栏支持展开/折叠、当前页高亮与祖先自动展开，展开状态持久化。

### 写操作

- 新建、改名、移动、删除、补齐配对、解除配对，全部带前置校验与失败补偿。
- 改名会同步改目录与笔记，笔记走宿主的改名接口，反链不断。
- 删除默认只删笔记，目录降级为分组目录；「连子页面一起删除」是独立选项。

### 正文里的子页面

- ```subpages 代码块列出当前笔记的子页面，列表与卡片两种视图。
- 只用笔记自身的路径定位页面，预览、多标签页、导出都不会指错。

### 排序

- 桌面拖拽排序：落在行中段成为子页面，落在行边缘同层排序，落在空白区移到根。
- 顺序存在页面根下的 `.subpage-order.json`，一个文件记录所有层级。

### 其他

- 中英双语界面，跟随 Obsidian 语言设置。
- 页面结构检查命令：孤立顺序条目、大小写冲突、可升级为父页面的目录。
- 与原生文件浏览器并存，另有命令一键折叠原生树。
- 桌面与移动端均已支持（拖拽仅桌面）。
