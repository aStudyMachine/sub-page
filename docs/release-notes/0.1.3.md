## English

### New

- Choose a new page root from the sidebar when the configured folder is missing.

### Changed

- The bundled organization skill explains the order for writing child and parent notes and identifies who maintains it.

### Fixed

- Switching page roots protects the new tree from actions opened under the previous root.
- Dragging a page beside another page in a different folder now moves it to the intended position.
- Keyboard navigation and F2 rename follow the focused result in sidebar search.
- Name sorting in `subpages` blocks uses natural order.
- Synced notes can appear in the tree even when the sync tool reports them as edits.

### Compatibility

- Requires Obsidian 1.15.0 or later on desktop and mobile.

## 简体中文

### 新增

- 配置的页面根目录不存在时，可以直接从侧栏重新选择。

### 变更

- 内置整理 Skill 补充了先写子页面、最后写父笔记的规则，并说明其维护归属。

### 修复

- 切换页面根目录后，旧菜单和弹窗里的操作不会误改新目录里的页面。
- 把页面拖到另一目录中某个页面的上方或下方时，会移动到预期位置。
- 侧栏搜索时，方向键和 F2 重命名会作用于当前聚焦的结果。
- 正文 `subpages` 列表按名称排序时使用自然顺序。
- 同步工具只报告修改事件时，新同步进来的笔记也能出现在页面树中。

### 兼容性

- 需要 Obsidian 1.15.0 及以上，支持桌面和移动端。
