## Sub Page 0.1.0

The first public release of Sub Page for Obsidian 1.15.0 and later.

- Browse and search your vault as a page tree, and create, rename, move, and reorder notes from the sidebar.
- Show child pages inside a note with a `subpages` block. Use a list or card grid with optional icons and descriptions.
- Create a parent folder when a note receives its first child. Sub Page can restore the parent to a regular note when it is the only item left in the folder.
- Preview and install the vault organization Agent Skill from settings. Choose its folder and optionally add an instruction to the vault’s `AGENTS.md`.

Upgrading from the internal 0.0.1 build imports manual order into the plugin’s configuration directory when needed. For manual installation, put `main.js`, `manifest.json`, and `styles.css` in your vault’s `.obsidian/plugins/sub-page/` folder, then enable Sub Page in Community plugins.

## 简体中文

Sub Page 首个公开版本，适用于 Obsidian 1.15.0 及以上版本。

- 在侧栏浏览和搜索笔记树，直接新建、改名、移动和排序。
- 在笔记中用 `subpages` 块显示子页面，支持列表、卡片以及可选的图标和描述。
- 笔记有了第一个子页面时创建配对目录。目录只剩父页面笔记时，可以自动将它还原为普通笔记。
- 在设置中预览并安装笔记整理 Agent Skill，可自选安装目录，并按需写入库内的 `AGENTS.md`。

从内部版 0.0.1 升级时，插件会在需要时把旧版手动顺序导入插件配置目录。手动安装请将 `main.js`、`manifest.json` 和 `styles.css` 放入库内的 `.obsidian/plugins/sub-page/` 目录，再在第三方插件设置中启用 Sub Page。
