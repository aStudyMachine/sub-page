## English

### Fixed

- If a note cannot be moved to the system trash, Sub Page reports the failure and preserves your manual sort order.
- If a page moves but its sort order or expanded state cannot be saved, the page tree refreshes and displays a warning.
- Copying a page link shows a warning if the page was moved or deleted after you opened the menu.
- If the clipboard is unavailable, you can select and copy the diagnostics from a dialog.

### Compatibility

- Requires Obsidian 1.15.0 or later on desktop and mobile.

## 简体中文

### 修复

- 笔记无法移到系统回收站时，显示删除失败并保留手动排序。
- 页面已移动但排序或展开状态未能保存时，刷新页面树并显示提示。
- 打开菜单后页面若已移动或删除，点「复制页面链接」会提示链接已失效。
- 剪贴板不可用时，可在弹窗中选中并手动复制诊断信息。

### 兼容性

- 需要 Obsidian 1.15.0 及以上，支持桌面和移动端。
