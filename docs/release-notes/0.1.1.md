## English

- Report failed system trash operations and retain manual ordering.
- Refresh the page tree after moves and report order or expansion state that could not be saved.
- Validate saved settings and offer selectable diagnostics when clipboard access fails.
- Provide GitHub build attestations for each release asset.

- 系统回收失败时提示用户并保留手动排序。
- 移动后刷新页面树，顺序或展开状态未能保存时显示提示。
- 校验保存的设置，剪贴板不可用时可从弹窗手动复制诊断信息。
- 为每个发布资产提供 GitHub 构建证明。
