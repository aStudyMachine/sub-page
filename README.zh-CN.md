# Sub Page

[English](README.md)

在 Obsidian 侧栏把笔记组织成可展开的页面树，也可以在笔记正文里用列表或卡片展示同一组子页面。打开已有笔记库即可浏览。

## 主要功能

- **浏览和搜索页面树**。子页面面板可以和 Obsidian 的文件列表并排使用。点父页面标题可以打开笔记并展开或折叠子页面，点图标可以单独切换列表。
- **新建和整理页面**。点侧栏的 **+** 新建页面，或右键已有页面选择**新建子页面**。桌面端拖到行中央可以移为子页面，拖到行上沿或下沿可以调整顺序。移动端长按页面可通过菜单上移或下移。
- **在正文展示子页面**。支持列表和卡片，也可以显示页面图标和描述。

## 开始使用

1. 点左侧功能区的**子页面**图标，或在命令面板运行 **Sub Page: 打开子页面面板**。面板首次打开时位于左侧栏。想给页面树腾出更多空间时，可运行 **Sub Page: 折叠原生文件浏览器**。
2. **页面根目录**留空时显示整个笔记库，也可在插件设置里选定一个目录。想看到没有页面的目录，可以开启**显示空目录**。
3. 在笔记中加入下面的代码块，再切换到阅读视图，即可看到这篇笔记的子页面。

   ````markdown
   ```subpages
   view: list
   sort: manual
   ```
   ````

## 笔记如何成为父页面

文件夹内与该文件夹同名的笔记就是父页面。例如 `Java/JVM/JVM.md` 是 JVM 父页面，`Java/JVM/垃圾回收.md` 是它的一个子页面。没有同名笔记的文件夹用来给页面分组。

新建页面时先生成普通笔记。首次新建或拖入子页面时，Sub Page 会把原笔记移进同名文件夹。**无子页面则删除文件夹，还原原本的页面**默认开启。文件夹里只剩原笔记时，插件会把笔记移回上一级，并将空文件夹移入库内回收站。上一级已有同名笔记时，会保留原来的文件夹。关闭设置可保留父页面的文件夹。

## 自定义子页面列表

| 选项 | 取值 | 默认值 |
| --- | --- | --- |
| `view` | `list` 列表或 `card` 卡片 | 插件设置 |
| `sort` | `name` 名称、`created` 创建时间、`modified` 修改时间或 `manual` 手动顺序 | 插件设置 |
| `show-icon` | `true` 或 `false` | `true` |
| `show-description` | `true` 或 `false` | `false` |
| `columns` | 卡片视图的列数 | `2` |
| `limit` | 显示数量上限，`0` 表示全部 | `0` |

可在笔记的 Obsidian 属性里添加 `icon` 和 `description`，设置图标和描述。图标可以写 `📁` 或 `lucide:folder`。

## 安装

支持桌面和移动端，需要 Obsidian 1.15.0 或更新版本。

手动安装时，将发布文件 `main.js`、`manifest.json` 和 `styles.css` 放进笔记库的 `.obsidian/plugins/sub-page/` 目录，重启 Obsidian，然后在**设置 → 第三方插件**中启用 **Sub Page**。[GitHub Releases](https://github.com/aStudyMachine/sub-page/releases)
